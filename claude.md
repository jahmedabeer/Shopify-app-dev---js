# Project Guidelines

## Project Overview
- **Type**: Shopify App (Development)
- **Framework**: React Router v7 (Remix)
- **Language**: JavaScript
- **ORM**: Prisma

## Documentation & Tool Usage

### Shopify-Related Queries
Use **Shopify MCP tools** for:
- **Liquid**: Templating language questions
- **GraphQL**: Admin API(https://shopify.dev/docs/api/admin-graphql), Storefront API queries
- **Polaris**: UI components and design system (https://shopify.dev/docs/api/app-home/using-polaris-components)

### React Router v7
- **Framework Mode Docs**: https://reactrouter.com/start/framework/installation
- Use for routing(https://reactrouter.com/start/framework/routing), loaders(https://reactrouter.com/start/framework/data-loading), actions(https://reactrouter.com/start/framework/actions), and framework features

### Polaris
- This app uses **Polaris Web Components** (`<s-page>`, `<s-button>`, etc.)
- No imports needed for Polaris components
- **Web components**: https://shopify.dev/docs/api/app-home/polaris-web-components

### Prisma
- **Docs**: https://www.prisma.io/docs/guides/react-router-7
- Use for database schema, migrations, and queries

## Development Notes
- Project is in **development phase**
- All code should be written in **JavaScript** (not TypeScript)
- Follow Shopify app best practices
- Use Polaris web components for consistent UI
